# Snowflake based AQI Pipeline

<b>Project Description:</b> We are getting Real-time Air Quality Index (AQI) Data from the API on an hourly basis. So, AQI means, its a standardized system used to measure and report air quality in a specific area. And It can range from 0 to 500.

It can be like:
- 0–50: Good
- 51–100: Moderate
- 101–150: Unhealthy for sensitive groups (e.g., children, elderly)
- 151–200: Unhealthy
- 201–300: Very Unhealthy
- 301–500: Hazardous


And common pollutants that are measured are like:
- PM2.5 (fine particulate matter)
- PM10 (larger particulate matter)
- O₃ (ozone)
- NO₂ (nitrogen dioxide)
- SO₂ (sulfur dioxide)
- CO (carbon monoxide)


Governments and environmental agencies (like India's CPCB) use the AQI to issue warnings, enforce regulations, and inform the public about air pollution and health risks.
